# Content & cross-workspace consistency audit — AI_Pilot.html

- File: `ai-pilot-v3/AI_Pilot.html` (2,295,845 bytes; 15,901 lines; 15 workspaces)
- Audit type: static, read-only. No browser was launched and the file was not modified.
- Method: grep + targeted `read` (offset/limit) + small PowerShell parses of the source data arrays. Every number below was counted from the file, not taken from the UI copy. Line numbers refer to the current file.
- Finding cap: 25. This report contains **12 findings** (1 high, 3 medium, 8 low) plus a verified-claims reconciliation section, because the numeric totals named in the brief turned out to be correct.

## First-run experience (static reading)

- Default view is Job Fit Studio with an empty drop zone and an explicit three-step header (“Drop / Review / Download”), plus a sample-load path; empty states name the next action.
- Radar auto-ranks on load (`init()` → `recomputeNow()`, L6395) using the prefilled profile, so it never shows an unactionable empty list.
- Work Sample Studio runs `render(readBrief())` at init (L9128), which fills completeness and the QA counter via `updateQaSummary` (L8957) — the static “0/0 checks recorded” (L3124) is replaced on first paint.
- Platform Analyzer pre-fills the first example and runs analysis at load (L3796, deliberately per the comment above it). A first-time user therefore sees populated project fields and generated outputs they did not enter; the outputs are watermarked synthetic, but the form fields are indistinguishable from user input. Worth a one-line “example loaded” notice (L1705 status is overwritten by the run) — not counted as a defect above.
- QA Gate populates its label/counters when the workspace is opened (`activateView('qa')` → `renderQA()`, L3731); its empty state explains that the verdict starts “Not ready”.

## Limitations

- No browser execution: dead controls are assessed by static wiring, not clicking. The repo’s `reports/baseline.json` (from a separate run) is consistent with this audit (15 view buttons, no duplicate ids) but was not used as evidence for the findings above.
- Counts are stable only for this revision; hard-coded “111” strings at L1661/L1665/L3338 and dynamic counters (L3327–L3328) will drift if `COMMANDS` changes. They currently agree.

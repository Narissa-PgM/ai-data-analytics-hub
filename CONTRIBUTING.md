# Contributing to AI Data Analytics Learning Hub

Thanks for considering a contribution! Here's how to help.

## Reporting a Bug or Typo

1. Check [existing issues](../../issues) first.
2. Open a new issue and include:
   - The module and topic name
   - What you expected vs. what you saw
   - A screenshot if it's a visual issue

## Suggesting a New Topic

Open an issue with the label `enhancement` and include:

- Which module it belongs to
- A one-line description
- Why it matters for analysts

## Submitting a Change

1. Fork the repo.
2. Create a branch: `git checkout -b fix/m4-mean-typo`
3. Follow the existing style:
   - Keep the tile → modal structure
   - Include a visual, a checklist, and an AI prompt
   - Use semantic HTML
4. Commit with a clear message: `Fix typo in Module 4 mean example`
5. Open a Pull Request.

## Style Guidelines

- **Tone:** Professional, direct, no fluff.
- **Examples:** Use synthetic data. Never real customer data.
- **AI models:** Note the check date if you mention a specific model.
- **Accessibility:** Include `aria-label`s on interactive elements.

## Code of Conduct

Be kind. Assume good intent. Focus on the work.
